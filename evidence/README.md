# Evidence provenance

The three `*-resource.json` files came from the Azure portal's JSON View on the deployed VNet and NSGs on 15 October 2026. The text was copied from the visible editor, parsed as JSON and saved before deletion. They are resource-state responses rather than exported deployment templates.

Publication transformations:

1. Replaced subscription identifiers within resource paths with `<subscription-id>`.
2. Removed `etag` and `resourceGuid` fields recursively.
3. Reformatted JSON with indentation.

No rule, subnet setting, provisioning state, resource name, binding or default rule was invented or changed during redaction. Azure returned uppercase subnet path components in the NSG responses; those are intentionally preserved. A deployment-template download attempt did not produce a usable file, so no template export is claimed.

`offline-verification.json` was generated by `scripts/verify.py` against these sanitized files. Its timestamp is the local test execution time, not a cloud deployment or packet-event timestamp. Its SHA-256 values identify the exact sanitized input bytes.

`cleanup-observation.txt` contains selected text from the portal accessibility capture, with UI indices and surrounding account details omitted. It is a transcription of UI evidence, not an Azure Activity Log export. Full screenshots, full accessibility captures and original resource JSON remain private; this repository publishes the sanitized records and explicit observations.

Screenshots are not synthesized. No network packets, endpoint logs, SQL sessions or Network Watcher diagnostic results are represented in this repository.
